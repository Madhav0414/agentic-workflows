# Workflows

Markdown SOPs that define what to do and how. Each workflow:
- States the objective clearly
- Lists required inputs
- Names which tools to call, in order
- Describes expected outputs
- Documents edge cases and known gotchas

## Workflows

| Workflow | Purpose |
|----------|---------|
| `generate_newsletter.md` | End-to-end newsletter pipeline: research → write → infographics → HTML → Gmail |
